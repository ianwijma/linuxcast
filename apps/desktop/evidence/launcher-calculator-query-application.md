## Result

An unmatched root query with an explicit number/math/colour signal can show one
local Calculate expression row with its canonical result. Classification uses
the existing bounded expression schema, pure evaluator and formatter, and needs
a shown/enabled registered Calculator. Ordinary words/bare constants, invalid,
domain, unsupported and oversized inputs do not become calculator results.
Registered-command matches keep their ranking. Existing explicit saved-search
choices remain alternatives; an available selected identity is retained.

The row has a local synthetic ID that never reaches generic Execute, preferences
or persistence. Deliberate current Arrow/Enter choice reevaluates the captured
expression and opens the existing Form/Result frames. Generic Calculator opens
empty. Edit/Cancel preserve root query/selection; Hide/dispose clears invocation
state. Existing Evaluate and the new entry share the same local helper.

Copy result is separate. Typing/classifying/choosing never copies, sends an
expression IPC, performs a network request or records use. Main still receives
only revision/expression on explicit Copy, recomputes canonical output and owns
the clipboard operation; renderer cannot supply arbitrary result text. Exact
receipts, unknown/no-replay and original-context checks remain. Copy checks the
current context immediately after pending publication before evaluating the API,
so a synchronous Back/dispose/query change cannot start a stale write.

No engine grammar, IPC, contract, dependency, migration, service, research or
proof lane was added. Full agreed local1.0 scope remains unchanged.
