## Behaviour and boundaries

Selected List row action Export quicklink (unencrypted JSON) discloses that the
file contains the saved name, full URL, tags and preferences and is not encrypted.
A fresh exact Get precedes the selection-only API. Literal/search and recovered
hidden definitions export without opening a browser or mutating definitions.
Main owns native file choice; no renderer path/target is accepted. After choice,
main rechecks full definition equality, frame, parent visibility and revision
before existing saveDataExport publishes private0600 JSON exclusively. It never
silently replaces an existing destination. Versioned native format contains one
validated QuicklinkRecord and no transient query, expanded URL, history, grants
or provider/account credentials. No definition is imported or executed.

Exact exported/cancelled ID/revision receipts are required. Cancel is not success.
Uncertain publication says the export may have completed and requires manual
Reload before another Export; this state survives Hide/reopen and gates only
Export. Metadata uncertainty also gates Export. Pending repeats and changed
query/selection/Back/Hide/dispose cannot claim late success or replay. Main aborts
staging best effort if original frame/lifecycle/revision leaves; an already
published file cannot be undone and is never described as cancelled.
