local calculator candidate. Require the existing calculatorExpressionSchema,
at least one explicit mathematical/number/colour signal `[0-9#()+*/^%-]`, a
shown/enabled registered Calculator command and an actual successful bounded
pure evaluateExpression + formatCalculationText result. Ordinary words and bare
word constants do not become candidates. Invalid/domain/unsupported/oversized
expressions offer no guessed calculation or simulated success. Existing explicit
Calculator command still supports its full current grammar. No new grammar,
dates/rate adapters, network or arbitrary evaluation is added in this increment.

Calculation section before existing explicit saved-search fallbacks. Title

their ranking; existing web-search choices remain explicit alternatives. Preserve
selected identity when it remains available; never switch a selected web-search
provider merely because a calculation candidate appears. Synthetic calculation
IDs never reach Execute/pin/alias/visibility/usage persistence. No clipboard or
expression IPC when typing, classifying or selecting a result.

At deliberate Arrow/Enter choice recheck current root view/revision/query/
selection and Calculator availability. A local CalculatorFlow.openExpression
entry accepts the captured expression, reevaluates with the existing pure engine
and opens the existing form/result frames (max total depth3), displaying exact
expression and canonical result. Refactor existing explicit Evaluate through the
same helper rather than forging host intents. Generic Calculator open stays
empty. Existing Edit expression/Back/Cancel preserve the captured local draft
and original root query/selection; Hide/dispose clears the invocation.

Copy result remains a separate deliberate action through the existing named
copyCalculatorResult({revision,expression}); main recomputes canonical output.
Held Enter from root choice cannot Copy. Original-context/lifecycle/reentrant
publication checks must run before API evaluation as well as after receipt, so a
subscriber leaving during pending publication causes zero Copy. No fake success,
arbitrary clipboard writer, paste, PRIMARY, history, remote request or implicit
fallback. Unknown outcome stays explicit; no automatic replay.
