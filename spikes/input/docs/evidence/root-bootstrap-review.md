## Private authority and process contract

FD3 must be an inherited connected AF_UNIX SOCK_SEQPACKET endpoint whose kernel creator is the actual root parent. `SO_PEERCRED`, `SO_PEERPIDFD`, parent identity, transport liveness, and `PDEATHSIG` checks bracket bootstrap and later reads. No bare-PID fallback authenticates a client. The root parent supplies only strict `{version, authorized_uid}` plus exactly one accepted connected AF_UNIX SOCK_STREAM descriptor. Unknown fields, root/sentinel UID, extra descriptors, truncated packets, wrong descriptor kinds, or lost parent fail closed. This is trusted root-fixture authorization, not a production polkit, service-grant, or public app API.

The accepted stream supplies the actual peer UID; it must match the root authorization. A bounded-buffer account lookup supplies its primary GID, independently of the peer's GID. Lookup occurs only before any worker/watchdog loop, under the independent seven-second engineering guard. The supervisor assigns connection generation 1 itself; no caller supplies an epoch, generation, executable, environment, session, or device path.

The root helper path is fixed to `/opt/linuxcast-input-spike/linuxcast-input-spike-denial-helper`; the file and parent directories must be root owned and nonwritable by group/others, with no symlink or set-ID executable. The child clears supplemental groups, sets every real/effective/saved UID/GID, clears capabilities and ambient capabilities, disables dumpability, sets no-new-privileges, and installs parent-death termination after credential changes. Inherited descriptors above FD3 are marked close-on-exec; the helper independently closes them before receiving its one metadata descriptor. Empty environment, fixed `/` working directory, nonroot consistent IDs, empty root-mode groups/capabilities, fixed protocol, and stable root-parent checks precede queries. The ordinary same-UID engineering mode remains available separately.

Inherited blocked SIGALRM/SIGTERM/SIGINT are rejected before guarded work; they cannot silently defeat the seven-/six-second bounds. The helper explicitly installs its alarm disposition. SIGCHLD must remain the default disposition with no SA_NOCLDWAIT before initialization and each child spawn/fork. These dedicated processes have no competing waitpid consumer, preserving the direct-unreaped-child identity used for cleanup. No signal mask, child-reaping policy, or deadline is weakened to obtain a pass.

The root entry emits at most 20 bounded rows with only a fixed phase, evidence/decision vetoes, and false `canArm`, `workerArmEmitted`, and `deviceBootstrapReached`. It calls the same `DecisionState` Arm/Renew logic as the manufactured supervisor route. Samples can veto and never Permit. A scheduled attempt that latches Pending stays incomplete even if a valid negative arrives later inside the 300 ms request deadline. There is no readiness wait, retry, rearm, or revival. The helper remains a six-second engineering process, not a persistent observer/service.
